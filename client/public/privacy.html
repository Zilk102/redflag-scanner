Политика обработки персональных данных

Редакция: 18.01.2026

1. Общие положения

Настоящая Политика определяет порядок обработки и защиты персональных данных пользователей сервиса «RedFlag Scanner» (далее — Сервис) в соответствии с Федеральным законом РФ №152-ФЗ «О персональных данных».

2. Оператор персональных данных

Оператор: самозанятый [ФИО исполнителя]
ИНН: [ИНН исполнителя]

3. Какие данные мы обрабатываем

  • Текст переписки, который пользователь самостоятельно вводит в поле или получает из распознанного текста на скриншоте.
  • Результат анализа, полученный от AI-модели.
  • Технические данные, необходимые для работы Сервиса (например, дата/время запроса).

Скриншоты переписок по умолчанию распознаются в браузере пользователя. Сервис не требует загрузки исходного изображения на сервер.

4. Цели обработки

  • Предоставление пользователю результата анализа переписки.
  • Поддержка работоспособности Сервиса и улучшение качества.
  • Исполнение требований законодательства РФ (при необходимости).

5. Правовое основание

Обработка персональных данных осуществляется на основании согласия субъекта персональных данных, выраженного путем установки отметки (чекбокса) на сайте перед отправкой текста на анализ.

6. Передача данных третьим лицам

Для выполнения анализа Сервис может передавать введённый пользователем текст в AI-сервис (YandexGPT). Передача осуществляется только в объёме, необходимом для выполнения анализа.

7. Сроки хранения

Данные могут храниться в базе данных Сервиса для обеспечения доступа к результату анализа. Пользователь может запросить удаление данных.

8. Права пользователя

  • Запросить информацию об обработке своих персональных данных.
  • Отозвать согласие на обработку персональных данных.
  • Потребовать уточнения, блокирования или удаления персональных данных.

9. Отзыв согласия и удаление

Пользователь может отозвать согласие и/или запросить удаление данных, связавшись с оператором.

10. Меры защиты

  • Ограничение доступа к данным и техническая защита инфраструктуры.
  • Минимизация объёма обрабатываемых данных.
  • Передача данных по защищённым каналам при размещении в production-окружении.
